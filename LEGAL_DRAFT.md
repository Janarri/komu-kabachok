# 1. Политика обработки персональных данных

## 1.1. Общие положения

Настоящая Политика описывает обработку персональных данных пользователей сайта «Кому кабачок?» (далее — Сайт). Оператор — Ябирова Юлиана Романовна (далее — Оператор).

По вопросам обработки данных можно написать на komukabachok-help@mail.ru.

Политика распространяется на сведения, которые пользователь предоставляет при использовании Сайта, а также на технические сведения, передаваемые используемыми Сайтом сервисами.

## 1.2. Какие данные могут обрабатываться

В зависимости от использования Сайта обрабатываются:
- идентификатор учётной записи;
- email, если пользователь привязал его к аккаунту;
- содержание объявлений: заголовок, описание, категория, количество, город, район, ориентир и выбранная точка/место передачи;
- фотографии объявлений;
- содержание сообщений в переписках;
- сведения о жалобах и уведомлениях;
- технические данные, необходимые для работы и защиты Сайта, включая данные, которые передаются браузером и инфраструктурой используемых сервисов.

Сайт не запрашивает паспортные данные, платёжные реквизиты или специальные категории персональных данных. Пользователям не следует самостоятельно публиковать такие сведения.

## 1.3. Цели обработки

Данные используются для:
1. создания и поддержания учётной записи;
2. размещения, отображения и управления объявлениями;
3. обеспечения переписки и уведомлений;
4. рассмотрения жалоб и обращений;
5. предотвращения спама, мошенничества и нарушений;
6. обеспечения работоспособности и безопасности Сайта;
7. исполнения обязанностей, предусмотренных законом.

## 1.4. Правовые основания

Обработка осуществляется на основаниях, предусмотренных законодательством РФ: для предоставления функций Сайта, исполнения пользовательского соглашения, соблюдения требований закона, а в случаях, когда это требуется, — на основании отдельного согласия пользователя.

Согласие на обработку персональных данных должно запрашиваться отдельно от пользовательского соглашения.

## 1.5. Публичность и доступ

Объявления и размещённые в них фотографии предназначены для просмотра посетителями Сайта и могут быть доступны неопределённому кругу лиц. Пользователь должен учитывать это до публикации и не указывать сведения, которые не хочет раскрывать.

Переписки не предназначены для публичного просмотра. Доступ к ним предоставляется участникам соответствующей переписки и техническим сервисам, обеспечивающим работу Сайта; доступ Оператора может потребоваться для безопасности и рассмотрения жалоб.

Публикация персональных данных для всеобщего доступа требует отдельной правовой оценки и, когда это предусмотрено законом, отдельного согласия на распространение.

## 1.6. Действия с данными

Оператор может осуществлять сбор, запись, систематизацию, накопление, хранение, уточнение, извлечение, использование, предоставление доступа в рамках функций Сайта, блокирование и удаление данных — с автоматизацией или без неё.

## 1.7. Используемые сервисы и место обработки

Сайт использует:
- GitHub Pages для размещения файлов сайта;
- Supabase для учётных записей, базы данных, переписок, уведомлений и хранения фотографий;
- API Яндекс Карт для отображения карт и геокодирования;
- CDN jsDelivr для загрузки библиотеки Supabase JS.

Проверенная конфигурация проекта Supabase: регион **eu-west-1 (Ирландия)**. По документации Supabase выбранный регион определяет размещение основной базы, Auth и Storage; журналы, резервные копии и иные подсистемы могут требовать отдельной проверки. Это означает, что сведения могут обрабатываться за пределами РФ.

Оператор обязан до публикации этой Политики и продолжения обработки определить применимость требований РФ о локализации и трансграничной передаче, выбрать законную архитектуру хранения и актуализировать этот раздел по фактической конфигурации. Наличие европейского региона само по себе не подтверждает соответствие требованиям российского законодательства.

Оператор не продаёт персональные данные.
